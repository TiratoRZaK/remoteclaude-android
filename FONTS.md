# Шрифты в приложении

Оформления используют шрифты Google Fonts под лицензией
[SIL Open Font License 1.1](https://openfontlicense.org/) — все с полной кириллицей.
Файлы лежат в `app/src/main/res/font/`.

| Файл | Шрифт | Авторы | Где используется |
|------|-------|--------|------------------|
| `cousine_regular.ttf` | Cousine | Steve Matteson (Ascender) | «Ночной терминал», «Аркада» — весь интерфейс; терминал в светлых оформлениях |
| `pt_serif_regular.ttf`, `pt_serif_bold.ttf` | PT Serif | ParaType (A. Korolkova, O. Umpeleva, V. Yefimov) | «Бумага и чернила», «Кофейня», «Летопись» — основной текст |
| `pt_sans_narrow_regular.ttf` | PT Sans Narrow | ParaType | «Синтвейв» — основной текст |
| `philosopher_regular.ttf`, `philosopher_bold.ttf` | Philosopher | Jovanny Lemonad | «Северное сияние» — всё |
| `pacifico_regular.ttf` | Pacifico | Vernon Adams, Jacques Le Bailly, Botjo Nikoltchev | «Кофейня» — заголовки |
| `rubik_mono_one_regular.ttf` | Rubik Mono One | Hubert & Fischer, Meir Sadan | «Синтвейв» — заголовки |
| `yeseva_one_regular.ttf` | Yeseva One | Jovanny Lemonad | «Бумага и чернила» — заголовки |
| `ruslan_display_regular.ttf` | Ruslan Display | Gayaneh Bagdasaryan | «Летопись» — заголовки |
| `press_start_2p_regular.ttf` | Press Start 2P | CodeMan38 | «Аркада» — заголовки и вкладки |

Терминал по умолчанию рисуется системным моноширинным шрифтом: у него шире всего набор
символов рамок, которые рисует Claude Code.
