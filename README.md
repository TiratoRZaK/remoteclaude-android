# remoteclaude-android

Нативный Android-клиент к личному серверу [remoteclaude](../remoteclaude): список живых
сессий Claude Code в локальной сети, чтение диалога, ввод промптов и управление
терминалом с телефона. Протокол тот же, что у веб-клиента, — сервер менять не нужно.

- Kotlin + Jetpack Compose (Material 3), minSdk 26, Gradle Kotlin DSL, version catalog.
- Сеть: OkHttp (HTTP + WebSocket), JSON — kotlinx.serialization.
- Слои: `:protocol` — протокол, эмулятор терминала, реконнект (чистая JVM, без Android);
  `:app` — Compose UI и ViewModel'и поверх него.

## Скачать

Последний APK — [releases/latest/download/app-debug.apk](https://github.com/TiratoRZaK/remoteclaude-android/releases/latest/download/app-debug.apk).
Ссылка всегда отдаёт свежий выпуск: открыть с телефона, разрешить установку из
браузера, поставить. Сборка отладочная и подписана debug-ключом — для домашней
установки этого достаточно.

## Что умеет

| Экран | Возможности |
|-------|-------------|
| Подключение | ссылка `http://192.168.1.40:7777/#t=<токен>` руками или сканированием QR, отдельное поле токена, проверка `GET /api/health`, адрес и токен в DataStore |
| Сессии | имя, каталог, число зрителей, геометрия, метка «чат»; обновление потягиванием |
| Сессия | вкладки «Чат» и «Терминал» поверх одного WebSocket, общий композер, плашки состояния |
| Настройки | текущее подключение и галерея оформлений с живым предпросмотром |

## Оформления

Оформление меняет шрифты, палитру, скругления, фон приложения и раскраску терминала
целиком. Выбирается в «Настройки → Оформление», применяется сразу и запоминается.

| Оформление | Как выглядит |
|------------|--------------|
| Ночной терминал | смоляной фон, фосфорная зелень, весь интерфейс моноширинным Cousine, острые углы |
| Бумага и чернила | тёплая бумага, заголовки Yeseva One, текст PT Serif, рыжие акценты, светлый терминал чернилами |
| Синтвейв | лиловый градиент, неоновые магента и циан, тяжёлый Rubik Mono One с разрядкой и узкий PT Sans Narrow |
| Северное сияние | холодный сине-зелёный градиент, бирюзовое свечение, Philosopher |
| Кофейня | эспрессо и сливки, рукописный Pacifico в заголовках, янтарный терминал |
| Аркада | индиго с жёлтым, пиксельный Press Start 2P, нулевые скругления |
| Летопись | пергамент и сепия, уставная вязь Ruslan Display, светлый терминал |

Шрифты вшиты в APK, интернет им не нужен; список и лицензии — в [FONTS.md](FONTS.md).
На светлых оформлениях бледные цвета из потока терминала притемняются, иначе
вторичный текст Claude сливался бы с бумагой.

Чат — пузыри пользователя справа, ответы Claude слева, вызовы инструментов строкой
«Bash · npm test»; автопрокрутка с кнопкой «↓ вниз». Плашка «Claude ждёт ответа в
терминале» появляется по `menuWaiting` и уводит на терминал.

Терминал — экранный буфер со скроллбэком, ANSI-цвета (16/256/truecolor), инверсия,
жирный, подчёркивание; кегль подбирается так, чтобы вся ширина сессии влезала в экран.
Панель быстрых клавиш (Esc, ⇧Tab, стрелки, Enter, Ctrl+C, Clear, 1–5) и кнопка
«Под экран», меняющая размер PTY под телефон. Промпт уходит вставкой в скобках
(`ESC[200~ … ESC[201~`) с переводом строки — многострочный текст попадает целиком.

Связь: автопереподключение с нарастающей паузой (1 с → ×2 → потолок 15 с), после
переподключения терминал очищается и буфер проигрывается заново. Кадр `exit` показывает
код возврата и больше не переподключается.

## Требования к сборке

- JDK 17 (проверено на Amazon Corretto 17.0.17).
- Android SDK: платформа `android-36`, build-tools 35+.
- Gradle не нужен — используется wrapper (Gradle 8.14.3, AGP 8.13.2, Kotlin 2.4.10).

Путь к SDK берётся из `local.properties` (`sdk.dir`), затем из `ANDROID_HOME` /
`ANDROID_SDK_ROOT`, затем из стандартных мест установки
(`%LOCALAPPDATA%\Android\Sdk`, `~/Android/Sdk`, `~/Library/Android/sdk`). Найденный путь
записывается в `local.properties` автоматически. Если SDK нет вовсе, модуль `:app`
не подключается к сборке, а JVM-часть остаётся рабочей.

## Сборка и установка

```bash
./gradlew test                 # юнит-тесты JVM (модуль :protocol)
./gradlew assembleDebug        # debug-APK
./gradlew installDebug         # собрать и поставить на подключённое устройство
```

APK появляется в `app/build/outputs/apk/debug/app-debug.apk`. Поставить вручную:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Релизная сборка (`./gradlew assembleRelease`) не подписана: подпись личным ключом
не настроена, для домашнего использования достаточно debug-APK.

### Выпуск новой версии

1. Поднять `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Закоммитить и поставить тег: `git tag v0.3.0 && git push origin main --tags`.
3. Гитхаб-экшен `.github/workflows/release.yml` соберёт APK, прогонит тесты и приложит
   `app-debug.apk` к релизу с этим тегом. Ссылка
   `releases/latest/download/app-debug.apk` начнёт отдавать новую сборку.

Сборку можно запустить и руками — вкладка Actions, workflow «APK и релиз»,
кнопка Run workflow: APK останется артефактом прогона.

### Если Android SDK не установлен

1. Скачать command line tools: <https://developer.android.com/studio#command-tools>,
   распаковать в `<SDK>/cmdline-tools/latest`.
2. Поставить компоненты и принять лицензии:

   ```bash
   sdkmanager --sdk_root=<SDK> "platform-tools" "platforms;android-36" "build-tools;36.0.0"
   sdkmanager --sdk_root=<SDK> --licenses
   ```

3. Указать путь сборке — либо переменной окружения `ANDROID_HOME=<SDK>`, либо строкой
   `sdk.dir=<SDK>` в `local.properties` (в пути прямые слэши).
4. `./gradlew assembleDebug`.

Без SDK работают только JVM-задачи: `./gradlew :protocol:test`.

## Как подключиться

1. На компьютере запустить сессию: `rclaude` во вкладке терминала.
2. Показать ссылку с токеном: `rclaude qr`.
3. В приложении нажать «Сканировать QR» (или вставить ссылку целиком) → «Проверить» →
   «Сохранить и продолжить».

Телефон и компьютер должны быть в одной сети; сервер слушает порт 7777 по HTTP, поэтому
приложение разрешает нешифрованный трафик (`usesCleartextTraffic`).

Для эмулятора вместо адреса компьютера удобнее туннель:
`adb reverse tcp:7777 tcp:7777`, адрес сервера — `http://127.0.0.1:7777`.

## Тесты

Юнит-тесты живут в `:protocol` и гоняются на JVM без эмулятора:

```bash
./gradlew test
```

Покрыто: разбор ссылки подключения, разбор и сборка кадров протокола, чат-события,
последовательности панели клавиш и вставка в скобках, нарастающая пауза, эмулятор
терминала (перенос, цвета, очистки, позиционирование, скроллбэк, альтернативный экран,
разрезанные между кадрами UTF-8 и CSI, изменение размера), потоковый UTF-8-декодер,
цикл переподключения на поддельном сокете и HTTP-клиент на локальном сервере.

## Что за рамками

- Создание и завершение сессий: сессии заводит `rclaude` на компьютере.
- Полный VT220: нет мыши, графики, двойной ширины символов и ответов на запросы
  состояния терминала — такие последовательности проглатываются.
- Горизонтальная прокрутка терминала: широкая сессия сжимается кеглем до 5.5sp, дальше
  строка обрезается — для узкого экрана есть кнопка «Под экран».
- TLS, доступ извне локальной сети, несколько серверов одновременно.
- Подписанный release-APK и публикация.
